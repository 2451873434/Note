# 高频率下读数据出错

## 问题现象

当qspi控制器的时钟频率为`600MHz`时，设置4分频时读取数据为异常数据，设置128分频时读取数据为正常数据，如下：

```bash
# flash中0x500000地址处的数据为AAAAAAAA

# 4分频
root@ft:/home/ft# ./rw -w 4 0x28008004 0x0300000a
root@ft:/home/ft# ./rw -r 4 0x28008004
[0000000028008004]: 0300000a
root@ft:/home/ft# ./rw -r 4 0x500000
[0000000000500000]: 555555D5

# 128分频
root@ft:/home/ft# ./rw -w 4 0x28008004 0x0300000f
root@ft:/home/ft# ./rw -r 4 0x28008004
[0000000028008004]: 0300000f
root@ft:/home/ft# ./rw -r 4 0x500000
[0000000000500000]: AAAAAAAA
```

## 原因

高频率下读取数据需要使用Fast Read指令（0Bh），而不是一般Read Data指令（03h）。

## 解决方法

### F1

在设备树中flash设备节点中添加“m25p,fast-read”属性。此时进OS后读取rd_cfg寄存器（04h），发现读指令为0Bh，分频系数为4分频。

```bash
root@ft:/home/ft# ./rw -r 4 0x28008004
[0000000028008004]: 0B04007A
root@ft:/home/ft# ./rw -r 4 0x500000
[0000000000500000]: AAAAAAAA
```

### F2

进OS后，手动配置rd_cfg寄存器。

```bash
root@ft:/home/ft# ./rw -w 4 0x28008004 0x0b04007a
root@ft:/home/ft# ./rw -r 4 0x28008004
[0000000028008004]: 0B04007A
root@ft:/home/ft# ./rw -r 4 0x500000
[0000000000500000]: AAAAAAAA
```

## 额外问题

有时候，用Fast Read指令去读取flash还是会有数据异常，这是由于读取数据的延时不够长，可以通过增加读取数据的延时来解决，如下：

```bash
# 8cycle
root@ft:/home/ft# ./rw -w 4 0x28008004 0x0b04007a
root@ft:/home/ft# ./rw -r 4 0x28008004
[0000000028008004]: 0B04007A
root@ft:/home/ft# ./rw -r 4 0x500000
[0000000000500000]: 55AAAAAA

# 32cycle
root@ft:/home/ft# ./rw -w 4 0x28008004 0x0b0401fa
root@ft:/home/ft# ./rw -r 4 0x28008004
[0000000028008004]: 0B0401FA
root@ft:/home/ft# ./rw -r 4 0x500000
[0000000000500000]: AAAAAAAA
```

> 大部分flash数据手册中，Fast Read指令（0Bh）对比Read Data指令（03h），在24-bit Address后加上了8个dummy clocks，即8cycle
