# 擦除异常

## 问题现象

​	在`3000M`上，`qspi`控制器下接`flash`无法进行擦除，但是其作为固件能够正常进系统，并且进系统安装驱动模块后，能够正常识别到`flash`的型号，并且能够对其正常读写，如下：

```
spi-nor spi-PHYT8009:00: gd25q128 (16384 kbytes)
```

## 原因

​	该型号的`flash`的适用电压为`3.3V`，`qspi`控制器使用的是`1.8V`，电压不足导致其无法正常完成擦除。

## 解决方法

​	更换适用`1.8V`的`flash`。

> 一般来说，带有`lq`关键字的`flash`为`1.8V`，如`gd25lq128d`，带有`q`关键字的`flash`为`3.3V`，如`gd25q128`
