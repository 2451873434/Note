# 创建延迟待机服务

**1、安装依赖工具**

```bash
# Ubuntu/Debian
sudo apt-get install xprintidle
# CentOS/RHEL/Fedora
sudo dnf install xprintidle
```

​	`xprintidle`工具通常在带有图形界面（如`X11`）的桌面环境中工作，它可以获取上次用户活动（如鼠标移动、键盘输入）以来经过的时间。

**2、创建服务脚本**

```bash
sudo vim /usr/local/bin/idle_standby.sh
```

```bash
#!/bin/bash

# --- 配置区域 ---
# 设置空闲时间阈值，单位：毫秒 (例如：10分钟 = 10 * 60 * 1000 = 600000)
IDLE_THRESHOLD=10000
# 检查间隔，单位：秒
CHECK_INTERVAL=5
# ----------------

while true; do
    # 获取当前系统空闲时间（毫秒）
    CURRENT_IDLE=$(xprintidle)

    # 判断空闲时间是否超过阈值
    if [ "$CURRENT_IDLE" -gt "$IDLE_THRESHOLD" ]; then
        # 如果超过阈值，执行待机指令
        # sudo echo inactive > /sys/power/standby会报permission denied
        sudo tee /sys/power/standby <<< inactive > /dev/null
    else
    	sudo tee /sys/power/standby <<< active > /dev/null
    fi

    # 等待指定的间隔时间后再次检查
    sleep $CHECK_INTERVAL
done
```

​	由于后续服务的`User=ft`，因此此脚本中使用了`sudo`，同时我们也需要设置相应的指令免密。

```bash
sudo visudo
# 在文件末尾添加（将[your_username]换成你的用户名）
your_username ALL=(ALL) NOPASSWD: /usr/bin/tee
```

​	最后赋予脚本文件可执行权限。

```bash
sudo chmod +x /usr/local/bin/idle_standby.sh
```



**3、创建`systemd`服务单元文件**

```bash
sudo vim /etc/systemd/system/idle-standby.service
```

```ini
[Unit]
Description=Idle Standby Service
After=multi-user.target graphical.target
Requires=graphical.target

[Service]
Type=simple
ExecStart=/usr/local/bin/idle_standby.sh
Restart=always
# User不能设置成root
User=[your_username]
# 在想显示屏幕的终端下用echo $DISPLAY查看
Environment=DISPLAY=:1

[Install]
WantedBy=multi-user.target
```

​	`xprintidle`需要在用户会话中运行。当你以`非root`用户登录桌面时，系统会生成一把“钥匙”（存在`~/.Xauthority`文件里），你的图形界面只认这把钥匙，而`root`身份运行的服务没有这把钥匙（`/root/`目录下没有`.Xauthority`文件），所以最后会出现报错`couldn't open display`。

**4、启用并启动服务**

```bash
# 重新加载systemd配置
sudo systemctl daemon-reload
# 启用服务，使其开机自启
sudo systemctl enable idle-standby.service
# 立即启用服务
sudo systemctl start idle-standby.service
```
