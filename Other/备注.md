# 备注



## 1、`ACPI`表位置

```
/sys/firmware/acpi/tables
```

## 2、同步硬件时钟

```
# 系统时间同步到硬件
hwclock --systohc
hwclock -w

# 硬件时间同步到系统
hwclock --hctosys
hwclock -s
```

## 3、修改bootargs参数

**修改内存大小**

添加`mem=8G`

**修改核数**

添加`nr_cpus=1`

## 4、查看当前内核的配置

```bash
$ zcat /proc/config.gz > ./config
$ cat config
```
