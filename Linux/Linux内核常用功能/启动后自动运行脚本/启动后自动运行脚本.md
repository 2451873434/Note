## 修改`etc/rc.local`文件

​	`/etc/rc.local`文件会在`Linux`系统各项复位都启动完毕之后再被运行。所以想要自己的脚本在开机后被运行，可以将脚本路径添加到该文件中。

> `Ubuntu`系统下是`/etc/rc.local`，`CentOS`系统下是`/etc/rc.d/rc.local`，笔者未测试过`CentOS`系统。

### 示例

​	创建如下脚本（注意要给脚本赋予可执行权限）：

```bash
# vim my_script.sh
#!/bin/sh
date >> /home/output.txt
```

​	将脚本添加到`/etc/rc.local`中，一般来说是最后一行。最后重启即可。

## 使用`crontab`

​	`crontab`是`Linux`下的计划任务，当时间达到设定的时间时，可以自动触发某些脚本运行。

​	当外面将`crontab`与`@reboot`结合起来使用的时候，就可以实现在系统重启后自动去运行某个脚本。

```bash
# crontab -e
@reboot /home/my_script.sh
```
