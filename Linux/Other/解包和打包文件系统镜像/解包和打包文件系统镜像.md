# 解包和打包文件系统镜像

## 1、已有文件系统镜像

​	如果已有一个文件系统镜像`ramdisk-buildroot.img`，使用其启动系统后发现缺少某个文件，则需要对其进行“解包--添加文件--重新打包”操作。

**1.确定镜像压缩格式**

```bash
file ramdisk-buildroot.img

# 未压缩的cpio归档
ramdisk-buildroot.img: ASCII cpio archive (SVR4 with no CRC)
```

**2.解包**

```bash
mkdir filesystem
cd filesystem

# 如果是gzip compressed data格式
zcat ../ramdisk-buildroot.img | cpio -idmv

# 如果是LZ4 compressed data格式
lz4 -dc ../ramdisk-buildroot.img | cpio -idmv

# 如果是未压缩的cpio归档
cpio -idmv < ../ramdisk-buildroot.img
```

**3.添加文件**

将需要加入的文件复制到解包目录中

**4.重新打包**

```bash
# gzip
find . | cpio -o -H newc | gzip > ../new_ramdisk.img

#lz4
find . | cpio -o -H newc | lz4 -l > ../new_ramdisk.img

# 如果是未压缩的cpio归档
find . -print0 | cpio -o -H newc -0 > ../new_ramdisk-buildroot.img
```
