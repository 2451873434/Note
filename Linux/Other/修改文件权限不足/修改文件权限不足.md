# 修改文件权限不足



## 问题描述

​	笔者在使用`UOS`系统时，该系统一般情况下只能使用用户权限而无法使用管理员权限，但是笔者又需要做`S3`休眠唤醒操作，普通用户默认没有权限修改系统的电源状态，使用`sudo echo mem > /sys/power/state`也不行。

## 问题原因

​	重定向符合`>`是由当前`shell`（比如`bash`）处理的，而不是由`sudo`处理的。所以，`sudo`只提升了`echo`命令的权限，但执行`>`写入文件时，还是你当前用户的权限，因此会失败。

## 解决方法

```bash
# 方法1
echo mem | sudo tee /sys/power/state

# 方法2
sudo bash -c `echo mem > /sys/power/state`
```
